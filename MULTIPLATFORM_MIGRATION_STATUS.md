## 2. Статус міграції ключових підсистем

### 2.1. Графічний рушій та рендеринг скла (Liquid Glass & Animation Cache)
- [x] **Рефрактивне рідке скло (`BackdropGlass`):** Апаратне розмиття Cogl/GLSL із хроматичною аберацією, спекулярними бліками та 1px відблиском.
- [x] **Централізований кеш (`MacAnimationCache`):** Бюджет VRAM/RAM 64 MB, автоматичне TTL-очищення (60 с), damage tracking на рівні вікон.
- [x] **Parallel Startup Barrier:** Завантаження стільниці менш ніж за 1.2 с через конкурентний бар'єр у `layout.js` та плавний 380 мс reveal.
- [x] **Fallback-підкладка Spotlight:** 0 мс матове скло без появи прозорих порожніх вікон.
- [x] **Mutter Animation Safe Re-entrance:** Безпечне переривання анімацій Overview та DING клонів без зависань.

### 2.2. Нативні системні бібліотеки (C / LD_PRELOAD Injections)
- [x] **`libmac_settings.so` (GNOME Control Center Injection):**
  - Точна геометрія бічної панелі: відступи 26px, відсутність білих розділювальних ліній.
  - Повна i18n локалізація (34 мови, включаючи українську «Пошук» та «Віджети»).
  - Керування параметрами розмиття, дока, екранних індикаторів (OSD) та стільниці в реальному часі.
- [x] **`libmac_nautilus.so` (Файловий менеджер):**
  - Капсульні hover-підкладки назв файлів із суворою взаємною винятковістю (`g_active_hover_item`).
  - Відсутність залипань підкладок на рівні `GtkGridView`.
  - Динамічні контекстні меню адаптивної ширини з вирівнюванням чекбоксів.
- [x] **`libmac_popover.so` / `libmac_terminal.so`:**
  - Стилізація поповерів, контекстних меню та скруглень вікна терміналу (28px).

### 2.3. Безпека, легальна чистота та захист цілісності
- [x] **Legal Isolation & Rebranding:**
  - Повне очищення від фірмових найменувань та прямих посилань на товарні знаки.
  - Використання FOSS-сумісних ідентифікаторів та нейтральних системних назв.
  - Шрифт за замовчуванням: `default` (з аліасом на високоефективний FOSS Inter / SF Pro без порушень прав).
- [x] **Цілісність розширень (`mac-extension-guard`):**
  - Автоматична щоденна перевірка та контроль версій (21/21 розширень зафіксовано в `config/extensions.lock.json`).
  - Захист від несанкціонованих оновлень та розсинхронізації коду.
- [x] **Single Source of Truth (`mac-audit-sync`):**
  - Бінарна ідентичність `libmac_settings.so` у 5 системних розташуваннях.
  - Повна узгодженість тем, іконок та налаштувань dconf.

## 3. Наступні кроки та пріоритети розробки

1. **Міграція на GNOME 47 / Mutter 47:**
   - Адаптація сигналів Clutter та нового API анімацій Mutter.
   - Оновлення оверлею `layout.js` для сумісності з GNOME 47+.
2. **Пакування в автономні дистрибутивні пакети:**
   - Створення `.deb` пакета для швидкої інсталяції без потреби локальної компіляції.
   - Створення скрипта верифікації сумісності з ядром та драйверами NVIDIA/AMD.
3. **Розширення автоматизованого тестування:**
   - Додавання stress-тестів для сесій під Wayland з багаторазовими змінами моніторів (Hotplug DP/HDMI).
