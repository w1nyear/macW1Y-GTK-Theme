# Аудит та статус локалізації macW1Y — 17.11.2026 / 18.11.2026

Цей документ фіксує результати комплексної інвентаризації, перенесення рядків, розширення каталогу та верифікації системи локалізації modpack macW1Y Sequoia / Tahoe Modpack (macW1Y Release).

«Перекладений каталог» означає наявність власного перекладу в компонентах; успішний англійський fallback сюди не зараховується і явно розрізняється у валідаторі.

## 1. Загальний стан мовного каталогу

- **Загальна кількість мов у каталозі:** **209** (194 базові мови каталогу + 15 нових найпоширеніших мов світу).
- **Загальна кількість уніфікованих ключів на мову:** **439 ключів** (покривають 100% компонентів системи).
- **Співвідношення рівнів (Tiers) у каталозі (`config/i18n/catalog.json`):**
  - **Tier 1 (Повністю перевірені людиною / Canonical):** **2 мови** (`uk` — українська, `en` — англійська).
  - **Tier 2 (Комплексні офіційні мови розширення):** **29 мов** (`de`, `fr`, `es`, `it`, `pt`, `nl`, `ro`, `hu`, `bg`, `hr`, `sr`, `sl`, `lt`, `lv`, `et`, `be`, `ru`, `cs`, `sk`, `tr`, `ja`, `ko`, `zh`, `zh_tw`, `hi`, `bn`, `th`, `vi`, `pl`).
  - **Tier 3 (Мови з підтримкою RTL — письмом справа-наліво):** **3 мови** (`ar` — арабська, `he` — іврит, `fa` — перська). Додатково прапорець RTL встановлено для `skr`, `ps`, `sd`, `ug`, `ur`.
  - **Tier 4 (Додаткові мови):** **175 мов**:
    - **24 мови з машинними чернетками (Machine-translated drafts):** `ace`, `af`, `ak`, `am`, `as`, `ast`, `ay`, `az`, `ba`, `yue`, `wuu`, `bho`, `nan`, `hak`, `cjy`, `hsn`, `awa`, `om`, `pcm`, `skr`, `gan`, `mwr`, `mag`, `hne`. Кожна містить 439 ключів зі 100% відповідністю плейсхолдерів. Позначені як `needs_review` і не видаються за перевірений людський переклад.
    - **151 мова з явним англійським fallback:** `english_fallback`.

## 3. Локалізація компонентів та інсталятора

### 3.1. GUI Інсталятор (`bin/mac-installer-gui`)
- **Меню вибору мови:** Розширено до підтримки всіх **209 мов** каталогу із самоназвами рідними мовами (Ukrainian: Українська, Arabic: العربية, Hebrew: עברית, Chinese: 简体中文, Saraiki: سرائیکی тощо).
- **Динамічне перемикання:** Вибір мови на екрані вибору негайно:
  1. Встановлює системний напрямок тексту `Gtk.TextDirection.RTL` для арабської, івриту, перської, сераїкі, урду, пушту тощо.
  2. Оновлює меню, кнопки та ярлики поточного екрана.
  3. Викликає `_rebuild_subsequent_screens()`, динамічно пересоздаючи всі наступні екрани (`screen_user`, `screen_options`, `screen_welcome`, `screen_disk`, `screen_progress`, `screen_reboot`) та верхній menubar.
- **Винесення зашитих рядків:** Усі зашиті повідомлення, заголовки, опис кроків інсталяції, розрахунки ємності диску, сповіщення помилок паролю та діалоги підтвердження замінено на виклики `self.tr(key)` через runtime `mac_i18n.py`.

### 3.2. Налаштування та системні діалоги (`bin/mac-apply-locale`, `bin/mac-styling-settings`)
- `bin/mac-apply-locale`: Інтегровано автоматичне завантаження з `catalog.json` усіх 209 мов, зі збереженням відповідних POSIX локалей, змінних середовища та конфігурацій AccountsService і PAM.

### 3.3. GNOME Shell розширення
- **21 кероване розширення** перевірено через `mac-extension-guard verify`.
- Власні рядки інтеграції меню та віджетів підключено через згенеровані модулі:
  - `extensions/appmenu@ChathurangaBW.github.io/mac_i18n.js`
  - `extensions/blur-my-shell@aunetx/components/mac_i18n.js`
  - `extensions/kiwi@kemma/apps/mac_i18n.js`

- Збережено всі upstream-переклади та ліцензійні заголовки.
- Оновлено контрольні суми в `config/extensions.lock.json` (21/21 LOCKED OK).
