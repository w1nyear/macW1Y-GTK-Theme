# Перевірка переносності інсталятора, 19 листопада 2026

Виправлено небезпечне видалення GNOME Shell без dpkg, запис GRUB у EFI stub Fedora, часткові оновлення pacman, мовчазне пропускання обов’язкових залежностей, використання готових бібліотек після невдалої компіляції. GDM використовує спільну базу dconf та визначає шлях custom.conf. PAM більше не переписується.

На RPM/Pacman вимкнено встановлення watchdog-обгортки Shell: системний виконуваний файл залишається під контролем пакетного менеджера. Стару обгортку розпізнаємо за сигнатурою і відновлюємо з .real; новий пакетний виконуваний файл не замінюємо старим.

Сім бібліотек збираються спочатку в тимчасовий каталог. Помилка зупиняє процес до копіювання. Інкрементальне оновлення також потребує локальної збірки. Додано залежності Nautilus та Python GI. Wine, Ubuntu-драйвери та пакети i386 вилучено з універсального обов’язкового списку; вони не є передумовою теми.

## Другий етап

- Nautilus і Параметри при наступному встановленні отримають обгортки у /usr/local/bin замість підміни пакетних файлів. Старі підміни розпізнаються за текстовою сигнатурою; нові пакетні виконувані файли не замінюються застарілими .orig.
- Nautilus, Параметри та Ptyxis віддають перевагу поточному системному виконуваному файлу, обходять власну обгортку та повертають 127, якщо оригінал відсутній. Пошук бібліотек охоплює multiarch-каталоги; прибрано персональний шлях vitaliy з обгортки Параметрів.
- Ярлики Nautilus і Параметрів явно запускають обгортки; Nautilus не обходить їх через DBusActivatable.
- Прибрано автоматичне встановлення GPU-драйверів, blacklist nouveau, зміну прошивок, лімітів CPU та активацію демона GameMode з повної інсталяції. Інкрементальне оновлення більше не застосовує CPU power limits, sysctl-профіль і NVIDIA runtime PM. Вже активні налаштування хоста не скасовувалися.
- Спільний генератор initramfs обирає initramfs-tools з конфігурацією, mkinitcpio з presets або dracut. Невідома конфігурація і помилки генератора не приховуються. Plymouth більше не запускає повторну генерацію через -R; список модулів initramfs-tools доповнюється, а не перезаписується.

## Незалежна перевірка виконання та виправлення Cogl (19 листопада, наступний етап)

Оцінка готовності: **70–75%, орієнтовно**. Попередні звіти про 100% встановлення
не підтверджують повну працездатність оболонки. Цей розділ уточнює їхні обмеження.

В окремому writable-overlay Fedora 41, GNOME 47.10, KVM, 2 vCPU / 2 ГБ,
з програмним рендерингом відтворено SIGSEGV у `cogl_pipeline_set_uniform_float`.
Typelib Cogl-15 описує вказівник value як scalar gfloat. Передавання масиву з GJS
призводило до падіння в `_cogl_boxed_value_set_x` / memcpy.

Виправлення:
- Liquid Glass: на GNOME 46/47 векторні uniforms розкладено на scalar uniforms,
  значення передаються через `set_uniform_1f`. На 48+ збережено array API.
  Оновлено src та dist, усі blur/composite pipelines. Версію 46 перевірено лише
  модульним тестом маршрутизації; реальний рендеринг перевірено на 47.
- Wi-Fi Hotspot: обробка відсутніх wireless toggle / binding source та пізніх
  async-відповідей після знищення меню.
- Desktop Widgets: відсутність GNOME Weather більше не перериває запуск усіх
  віджетів; наявні fallback джерела локації залишаються доступними.
- AppIndicators: додано локальну GSettings-схему з установленого пакунка Ubuntu;
  розширення не залежить від глобальної схеми Ubuntu. XML компілюється --strict.
- mac-extension-guard: прибрано абсолютний шлях до користувача vitaliy;
  встановлений скрипт читає /usr/share/mactheme/config/extensions.lock.json.
  Відсутній, порожній чи некоректний lock тепер означає помилку, а не успіх
  перевірки нульової кількості розширень. Перевіряються metadata.json/extension.js.
  Інсталятор розгортає lock під час повного й інкрементального встановлення.

Підсумок повторного runtime-тесту після розгортання актуального snapshot та
компіляції схем: Shell працює 25 секунд, **20/21 керованих розширень ENABLED**,
без ERROR серед цих 20. DING відсутній. Машинний результат:
`2026-11-19-fedora-runtime.json`. SIGSEGV Cogl повторно не виник.
Це короткий headless smoke test, не доказ відсутності графічних дефектів.
У журналах є попередження середовища без повної GNOME session, теми та cleanup/GC.
Виявлено порожні staged extension-updates для user-theme та DDC, які заважали
повторним запускам; у тестовій VM їх перенесено в ~/review-quarantine.

Хост: 17/17 модульних тестів, guard 21/21, audit-sync 100% PASS, bash -n PASS,
