Нижче наведено детальний опис кожного файлу: його призначення, точний цільовий
шлях у системі та точна команда для переміщення / встановлення.

  1) `~/.themes/MacTahoe-Dark/gnome-shell/gnome-shell.css`

• Що робить цей файл:

  - Окремі заокруглені пілюлі (`border-radius: 9999px`) для повзунків звуку та яскравості.

5. ГОТОВИЙ СКРИПТ АВТОМАТИЧНОГО ВСТАНОВЛЕННЯ (INSTALL.SH)
--------------------------------------------------------------------------------
Цей скрипт збережено у файлі: `install.sh` поруч із `done.txt`.
Для розгортання теми на будь-якій системі достатньо виконати:
`bash install.sh`

Вміст скрипта:
```bash
#!/usr/bin/env bash
set -e

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
echo "==> Встановлення теми macOS 26 для Ubuntu..."

# 1. Створення цільових папок
mkdir -p ~/.themes/MacTahoe-Dark/gnome-shell
mkdir -p ~/.themes/MacTahoe-Dark-solid/gnome-shell
mkdir -p ~/.local/share/gnome-shell/extensions/blur-my-shell@aunetx/components/popup
mkdir -p ~/.local/share/gnome-shell/extensions/blur-my-shell@aunetx/effects
mkdir -p ~/.local/share/gnome-shell/extensions/blur-my-shell@aunetx/styles

# 2. Копіювання теми GNOME Shell
echo "==> Копіювання файлів теми..."
cp "$SCRIPT_DIR/gnome-shell-theme/gnome-shell.css" ~/.themes/MacTahoe-Dark/gnome-shell/gnome-shell.css
cp "$SCRIPT_DIR/gnome-shell-theme/gnome-shell.css" ~/.themes/MacTahoe-Dark-solid/gnome-shell/gnome-shell.css

# 3. Копіювання файлів Blur My Shell
echo "==> Копіювання компонентів Blur My Shell..."
BMS_TARGET="$HOME/.local/share/gnome-shell/extensions/blur-my-shell@aunetx"
cp "$SCRIPT_DIR/blur-my-shell/extension.js" "$BMS_TARGET/extension.js"
cp "$SCRIPT_DIR/blur-my-shell/components/menubar.js" "$BMS_TARGET/components/menubar.js"
cp "$SCRIPT_DIR/blur-my-shell/components/quick_settings.js" "$BMS_TARGET/components/quick_settings.js"
cp "$SCRIPT_DIR/blur-my-shell/components/notifications.js" "$BMS_TARGET/components/notifications.js"
cp "$SCRIPT_DIR/blur-my-shell/components/dash_to_dock.js" "$BMS_TARGET/components/dash_to_dock.js"
cp "$SCRIPT_DIR/blur-my-shell/components/popup/targets.js" "$BMS_TARGET/components/popup/targets.js"
cp "$SCRIPT_DIR/blur-my-shell/effects/gradient_panel.glsl" "$BMS_TARGET/effects/gradient_panel.glsl"
cp "$SCRIPT_DIR/blur-my-shell/effects/gradient_panel.js" "$BMS_TARGET/effects/gradient_panel.js"
cp "$SCRIPT_DIR/blur-my-shell/effects/effects.js" "$BMS_TARGET/effects/effects.js"
cp "$SCRIPT_DIR/blur-my-shell/effects/effect_groups.js" "$BMS_TARGET/effects/effect_groups.js"
cp "$SCRIPT_DIR/blur-my-shell/styles/panel.css" "$BMS_TARGET/styles/panel.css"

# Налаштування заокруглення Dash to Dock (28px як у MacTahoe)
D2D_DIR="$HOME/.local/share/gnome-shell/extensions/dash-to-dock@micxgx.gmail.com"
if [ -f "$D2D_DIR/stylesheet.css" ]; then
    sed -i 's/border-radius: 24px;/border-radius: 28px;/g' "$D2D_DIR/stylesheet.css" 2>/dev/null || true
fi

# 4. Імпорт налаштувань Dconf
echo "==> Завантаження параметрів Dconf..."
if [ -f "$SCRIPT_DIR/dconf/blur-my-shell.dconf" ]; then
    dconf load /org/gnome/shell/extensions/blur-my-shell/ < "$SCRIPT_DIR/dconf/blur-my-shell.dconf"
fi
if [ -f "$SCRIPT_DIR/dconf/dash-to-dock.dconf" ]; then
    dconf load /org/gnome/shell/extensions/dash-to-dock/ < "$SCRIPT_DIR/dconf/dash-to-dock.dconf"
fi
if [ -f "$SCRIPT_DIR/dconf/gnome-shell.dconf" ]; then
    dconf load /org/gnome/shell/ < "$SCRIPT_DIR/dconf/gnome-shell.dconf"
fi

# 5. Налаштування параметрів GSettings
echo "==> Налаштування інтерфейсу GNOME..."
gsettings set org.gnome.desktop.interface clock-show-weekday true
gsettings set org.gnome.desktop.interface clock-show-date true
gsettings set org.gnome.desktop.interface clock-format '24h'
gsettings set org.gnome.shell.extensions.appindicator compact-mode-enabled true
dconf write /org/gnome/shell/extensions/user-theme/name "'MacTahoe-Dark'"

# 6. Перезапуск розширень
echo "==> Перезапуск розширень..."
gnome-extensions disable blur-my-shell@aunetx 2>/dev/null || true
gnome-extensions disable dash-to-dock@micxgx.gmail.com 2>/dev/null || true
sleep 1
gnome-extensions enable dash-to-dock@micxgx.gmail.com 2>/dev/null || true
gnome-extensions enable blur-my-shell@aunetx 2>/dev/null || true

echo "==> Встановлення успішно завершено!"
```

## ЧАСТИНА 2: ЖУРНАЛ ВИКОНАНИХ ЗМІН (ХРОНОЛОГІЯ ТА ЕТАПИ)
================================================================================

--------------------------------------------------------------------------------
ЕТАП 1: Меню бар (MenuBar) — Затемнення та Блюр
--------------------------------------------------------------------------------
- Створено кастомний шейдерний ефект для Blur My Shell: `Gradient Panel (Darkness and Blur)`.
- Синхронізовано `clip_y0` та `clip_height`, що забезпечує 100% точний вертикальний градієнт від 0.0 до 1.0.
- Додано можливість незалежно регулювати:
  - Затемнення: зверху (Top darkness) та знизу (Bottom darkness)
  - Розмиття: зверху (Top blur) та знизу (Bottom blur)

--------------------------------------------------------------------------------
ЕТАП 2: Контрол Центр / Quick Settings (справа вгорі)
--------------------------------------------------------------------------------
Задача: 
- Видалити загальний темний фон контейнера Control Center (елементи вільно плавають).
- Додати тіні під елементами та напівпрозоре скло (liquid glass).

ЕТАП 13: Оптимізація та фізика анімації Magic Lamp (Крива швидкості Ease та Синхронне розширення шийки)

Що реалізовано:
1. Математична модель кривої швидкості Ease (поліном Ерміта):
   - Реалізовано функцію _easeMac(t) = 6*t^2 - 8*t^3 + 3*t^4.
   - Похідна v(t) = 12*t*(1 - t)^2 досягає піку швидкості рівно при t = 1/3 (перша третина руху).
   - У наступних двох третинах (від 1/3 до 1.0) швидкість монотонно та неперервно спадає до v(1) = 0, забезпечуючи ідеально м'яку посадку меню без ривків чи різких зупинок.

   - Верх меню починає плавно розширюватися з кнопки одночасно з початком руху вниз.
   - Досягає повної ширини (pX = 1.0) рівно на половині анімації (pY = 0.5) за плавною синусоїдальною кривою ease: pX = sin((pY / 0.5) * PI / 2).
   - Похідна в точці 0.5 дорівнює нулю, що гарантує безшовний перехід: у другій половині анімації меню вже є ідеально рівним прямокутником і плавно допливає до своєї повної висоти.
   - При закритті процес відбувається дзеркально: у першій половині меню скорочується знизу вгору як прямокутник, а після проходження половини плавно втягується у вузьку кнопку.

   - Враховано природне положення руки користувача: пальці розташовані вертикально (span_y >= 750) або горизонтально (span_x >= 750).
   - При свайпі вліво/вправо (|Δx| >= 40) миттєво відкривається вікно перемикання Alt+Tab (WindowSwitcherPopup).
   - Усунено тайм-аут закриття та затримку прозорості: перемикач з'являється негайно та плавно гортає вікна зі швидкістю руху пальців.
   - Підняття пальців активує вибране вікно та переводить його на передній план.

2. РЕАЛЬНЕ ПЕРЕМІЩЕННЯ ВІКОН І ФАЙЛІВ ТРЬОМА ПАЛЬЦЯМИ РАЗОМ (ФОРМА КОЛА):
   - Коли три пальці тримаються разом компактною групою (коло: span_x < 800, span_y < 800, max_dist < 900):
     * Якщо курсор розташований над вікном: GNOME Shell розширення macos-touchpad-gestures@mactheme знаходить це вікно та безпосередньо рухає його (win.move_frame) разом із вказівником миші. Більше не потрібно хапати заголовок вікна — вікно рухається з будь-якого місця!
     * Якщо курсор на робочому столі або файлі: демон емулює натискання лівої кнопки миші (BTN_LEFT DOWN) та рухає курсор, плавно перетягуючи файл/об'єкт по екрану.
     * При піднятті пальців переміщення завершується, вікно або файл фіксується на новому місці.

3. ПІДГРУПА «ПЕРЕМІЩЕННЯ» У ПАРАМЕТРАХ ТАЧПАДА ТА РЕЖИМ «ВВЕСЬ ЕКРАН»:
   - У Параметри -> «Миша та сенсорний пристрій» -> вкладка «Сенсорний пристрій» інтегровано нову підгрупу «Переміщення»:
     * Доступний вибір режимів: «Ввесь екран» (за замовчуванням) та «Звичайний».
     * Режим «Ввесь екран»: повне охоплення — кожен міліметр тачпада пропорційно відповідає пікселям екрана (верхній правий кут тачпада відповідає верхньому правому куту екрана, лівий нижній — лівому нижньому). Це дозволяє перемістити файл або вікно через увесь екран 1920x1080 в один легкий рух без відриву пальців.
     * Режим «Звичайний»: стандартне відносне переміщення.
     * Налаштування зберігається в ~/.config/mac-touchpad.conf та миттєво зчитується демоном і розширенням.

4. ВИПРАВЛЕННЯ ЩИПКІВ КОПІЮВАННЯ ТА ВСТАВКИ (CTRL+C / CTRL+V):
   - Раніше надсилалися віртуальні keyval події Clutter, які не доходили до вікон додатків у сесії Wayland.
   - Тепер при щипку на себе (scale <= 0.82) розширення надсилає сигнал CMD_COPY до апаратного демона, а демон через ядро (/dev/uinput) генерує справжні апаратні скан-коди KEY_LEFTCTRL + KEY_C.
   - При щипку від себе (scale >= 1.18) генеруються апаратні скан-коди KEY_LEFTCTRL + KEY_V.
   - Тепер файл, текст або об'єкт насправді копіюється і вставляється в будь-якому додатку (Nautilus, браузер, редактор коду тощо), супроводжуючись красивим OSD-індикатором "Скопійовано" / "Вставлено".
